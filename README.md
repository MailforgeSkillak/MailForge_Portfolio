# MailForge by Skillak — Complete Interactive Project Showcase

**Version 7 — Expanded Product Showcase + Latest Workspace Screens**

موقع تفاعلي عربي/إنجليزي المصطلحات يعرض MailForge بصورة شاملة: قصة المشروع والمشكلة والحل، الجمهور المستهدف، حالات الاستخدام، كتالوج وحدات المنصة، أدوات الذكاء الاصطناعي العشر، رحلة الإرسال، المنافسين، نموذج العمل، المرحلة الحالية، الإضافات المستقبلية، والأسئلة الشائعة. يضم الإصدار الحالي أيضًا سبع لقطات حديثة لمساحة العمل، موزعة داخل كتالوج الوحدات ومعرض الصور.

## التشغيل

- افتح `index.html` لمعاينة الموقع.
- يفضّل تشغيله عبر خادم محلي بسيط: `python -m http.server 8080` ثم فتح `http://localhost:8080`.
- لوحة الإدارة: `http://localhost:8080/admin.html`.
- لا يحتاج المشروع إلى Node.js أو npm أو Build step.

## الاستضافة الحالية

- GitHub Repository: `MailforgeSkillak/MailForge_Portfolio` لحفظ الكود والصور وملف المحتوى وسجل التغييرات.
- AWS Amplify Hosting: نشر الموقع الثابت عبر ربط GitHub.
- الفرع المتصل: `main`.
- إعداد المشروع: Framework `None`، أمر البناء فارغ، ومجلد الإخراج جذر المستودع `/`، مع تعطيل SSR.
- راجع `HOSTING_SETUP_AR.md` لمعلومات النشر والربط.

## إدارة المحتوى

- `admin.html`: تعديل النصوص ومواضع الصور الـ23 وإضافة لقطات معرض مخصصة.
- `portfolio-content.json`: النصوص وروابط الصور المنشورة.
- `assets/`: الشعار ولقطات المنتج الأصلية، بما فيها سبع لقطات جديدة لمساحة العمل.
- `assets/managed/`: صور يتم استبدالها أو رفعها من لوحة الإدارة عند النشر.
- المسودات تبقى محليًا في LocalStorage/IndexedDB حتى نشرها إلى GitHub.
- نشر GitHub يستخدم Fine-grained Token محدودًا بمستودع واحد؛ لا تخزن Token في ملفات الموقع أو في مستودع GitHub.

## أقسام العرض الشامل

الإصدار الحالي يتكون من 23 قسمًا/Section، ويضم 37 وحدة في كتالوج الصفحات (8 مجموعات عامة + 23 صفحة مساحة مستخدم + 6 مجموعات إدارة)، و10 أدوات AI، و6 Playbooks قطاعية، و5 منافسين/بدائل رئيسية. معرض الصور يضم 22 لقطة افتراضية: 15 لقطة أساسية و7 لقطات لمساحة العمل.

5. MailForge Intelligence — عشرة أدوات AI.
6. رحلة المستخدم من التسجيل إلى التحليل والتوسع.
7. معرض لقطات المنتج الحقيقية وأحدث لقطات مساحة العمل.
8. دورة الإرسال والسلامة والخصوصية.
9. المشهد التنافسي ومصفوفة المقارنة.
10. نموذج العمل ومصادر الإيراد المقترحة.
11. المرحلة الحالية وخارطة الطريق.
12. فرص التوسع والإضافات المستقبلية.
13. الأسئلة الشائعة.

## حالة المنتج ودقة الادعاءات

وفق المعلومات التي قدمها صاحب المشروع: المنتج في مرحلة التطوير، لا يوجد عملاء حاليون، وتمت اختبارات إرسال داخلية عبر Gmail وOutlook. يعرض الموقع ذلك بصراحة ولا يقدم هذه الاختبارات كدليل على جاهزية إنتاجية أو Traction تجاري.

- لا توجد وعود بضمان وصول Primary Inbox أو منع Spam.
- سقف 400 رسالة/24 ساعة هو حد داخلي في تصميم MailForge، وليس حدًا رسميًا لمزود البريد.
- لا يوجد ادعاء بأن كل بيانات المستخدم محفوظة على جهازه فقط.
- أدوات AI موصوفة من وثائق المشروع ويجب اختبار كل مسار ومخرجاته قبل وصفه كمكتمل إنتاجيًا.
- المقارنة مع المنافسين توضح التموضع والميزات العامة حسب صفحات رسمية، وليست Benchmark مستقلًا أو ادعاء تفوق.
- الأهداف المالية والميزات المستقبلية ليست نتائج محققة.
- البيانات والأعداد الظاهرة داخل لقطات الشاشة هي بيانات واجهة كما وردت في الصور، ولا تُعرض بوصفها نتائج تجارية.

## الأمان والخصوصية

هذا Portfolio عام ولا يجب استخدام GitHub لتخزين بيانات عملاء أو قوائم بريد أو بيانات دفع أو أسرار. إذا تحول إلى نظام يتلقى بيانات خاصة، يلزم Backend ومصادقة وصلاحيات وتخزين خاص. لوحة `admin.html` ليست محمية بتسجيل دخول حقيقي لمجرد كونها صفحة منفصلة.
