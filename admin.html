REPOSITORY SETTINGS

إعداد مستودع GitHub

أدخل بيانات المستودع الذي يحتوي على index.html وملفات الموقع.

⌘
صلاحيات الرمز المطلوبة: Repository access لمستودع واحد فقط، ثم Contents: Read and write وMetadata: Read. لا تستخدم Token بصلاحيات Account كاملة، ولا تضعه داخل ملفات المشروع.

ماذا يحدث بعد النشر؟

تُرفع الصور الجديدة إلى assets/managed/ ويُحدّث ملف portfolio-content.json في Commit واحد. إذا ربطت المستودع بتطبيق AWS Amplify، فكل تحديث على الفرع المحدد يطلق بناءً ونشرًا تلقائيًا للموقع.

ماذا لا يفعل هذا النظام؟

GitHub هنا مستودع مصدر وملفات عامة للموقع، وليس مساحة تخزين لبيانات زوار أو عملاء. لا ترفع قوائم بريد أو مستندات خاصة أو معلومات حساسة. إذا احتجت ملفات خاصة لاحقًا، أنشئ Backend وتخزينًا بصلاحيات حقيقية.
